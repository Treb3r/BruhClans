# BruhClans

Высокопроизводительный плагин клановой системы для серверов Minecraft (Paper 1.21+) с поддержкой кастомных ресурс-паков, меню, системы прокачки, хранилища, точек баз и подсветки/окраски брони.

## Возможности

- **Клановое меню и GUI**:
  - Полная поддержка современных кастомных шрифтов, кастомных моделей предметов (`CustomModelData`) и 24-битных RGB HEX цветов.
  - Разделы: «Информация», «Участники», «Уровень», «Топ кланов», «Точки баз», «Поручения», «Цвет брони», «Испытания», «Хранилище».
- **Цвет брони клана**:
  - 14 предустановленных цветов палитры с возможностью выбора индивидуального цвета участника или цвета всего клана.
  - Кулдауны, защита от спама и синхронных I/O зависаний.
- **Хранилище клана**:
  - Система постраничного хранилища и аренда дополнительных ячеек за клановый баланс.
- **Интеграции**:
  - [Vault](https://github.com/MilkBowl/VaultAPI) — внутриигровая экономика.
  - [PlaceholderAPI](https://github.com/PlaceholderAPI/PlaceholderAPI) — плейсхолдеры кланов.
  - [ProtocolLib](https://github.com/dmulloy2/ProtocolLib) — сетевые пакеты и анимации.

## Сборка

Требования:
- Java 21+
- Apache Maven 3.8+

```bash
mvn clean package -DskipTests
```

Собранный jar-файл будет находиться в папке `target/bruhstudio-1.0.0.jar`.
